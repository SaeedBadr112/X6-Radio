# 📻 تطبيق الراديو | Desktop & Mobile

**هذا المشروع** هو تطبيق مفتوح المصدر يعمل على:
- 💻 نسخة سطح المكتب (Windows/Electron)
- 📱 نسخة الجوال (Android/iOS)

---

## ✨ الميزات الرئيسية | Main Features
- 🎙️ آلاف المحطات الإذاعية العربية والعالمية.
- 🌐 دعم كامل للغتين العربية والإنجليزية.
- 🎛️ مؤثرات صوتية متقدمة (Compressor, Stereo, Output Device).
- ⏱️ مؤقت إيقاف التشغيل + مؤقت تصاعدي.
- 🔴 تسجيل البث المباشر وحفظه.
- ❤️ المفضلة وسجل الاستماع.
- 🔍 بحث محلي وعالمي عبر Radio Browser API.
- 🎨 مظاهر متعددة (افتراضي، داكن، فاتح، أحمر).
- 📦 تحديث تلقائي عبر GitHub Releases.
- ⌨️ اختصارات لوحة مفاتيح شاملة.

---

## 🚀 تنزيل التطبيق | Download
- **Windows (Desktop)**: حمل ملف `.exe` من صفحة الإصدارات.
- **Mobile (Android/iOS)**: حمل ملف `.apk` أو `.ipa` من نفس الصفحة.

---
